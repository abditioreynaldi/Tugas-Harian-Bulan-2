## Tiga hal yang saya pelajari

1. `const` mencegah binding variabel diganti, tetapi properti object atau isi array yang dirujuknya tetap bisa diperbarui.
2. Tipe data memengaruhi operator: `+` bisa menggabungkan string, sementara operasi seperti `*` mengubah string numerik menjadi angka.
3. Array memakai indeks mulai dari nol, dan mengakses indeks yang belum ada menghasilkan `undefined` tanpa selalu menimbulkan error.
